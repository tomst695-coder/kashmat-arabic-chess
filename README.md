# كش مات — شطرنج عربي

لعبة شطرنج عربية باتجاه RTL، تعمل كتطبيق ويب تقدّمي (PWA) ويمكن تثبيتها على Windows وLinux وAndroid وiOS. لا تحتاج إلى حساب أو خدمة خلفية، وتُحفظ المباراة على الجهاز.

## المزايا

- خصم آلي بثلاث درجات صعوبة، وتقييم لكل نقلة للطرفين.
- قواعد الشطرنج الأساسية: النقلات القانونية، الكش والكش مات، التبييت، الأخذ بالتجاوز، ترقية البيدق، والتعادل.
- استعادة المباراة بعد إغلاق الصفحة أو إعادة تشغيلها.
- تلميح، تراجع عن آخر دور، قلب الرقعة، وسجل للنقلات.
- تصميم متجاوب بالعربية، أيقونات تثبيت مناسبة للهواتف، وتشغيل دون اتصال بعد أول زيارة.
- تحكم بلوحة المفاتيح في الرقعة: الأسهم للتنقل وEnter أو Space لاختيار المربع.
- لا توجد مكتبات خارجية أو خطوط تُحمّل من الإنترنت.

## التشغيل والتطوير

يتطلب Node.js 20 أو أحدث. من مجلد المشروع:

```sh
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية (`http://localhost:4173`). لإنشاء نسخة ثابتة للنشر:

```sh
npm run build
npm run preview
```

تُنشأ النسخة الجاهزة داخل `dist/`. انشر محتوياتها على استضافة تدعم HTTPS كي تعمل ميزات التثبيت والعمل دون اتصال. التطبيق نفسه لا يحتاج اتصالًا بعد تحميله وتخزينه في المتصفح.

في مستودع GitHub، اختر **Settings → Pages → Source: GitHub Actions** مرة واحدة. بعدها ينشر سير العمل نسخة اللعبة تلقائيًا على GitHub Pages عند تحديث الفرع `main`، ويشغّل الاختبارات والبناء قبل النشر.

لتشغيل اختبارات قواعد اللعب قبل إرسال تعديل:

```sh
npm test
```

تعمل الاختبارات والبناء تلقائيًا في GitHub Actions مع كل طلب سحب أو تحديث للفرع.

## التثبيت على الأجهزة

| الجهاز | طريقة التثبيت |
| --- | --- |
| Windows | افتح الموقع في Edge أو Chrome واختر تثبيت التطبيق من شريط العنوان أو قائمة المتصفح. |
| Linux | افتح الموقع في متصفح Chromium يدعم تطبيقات الويب التقدمية واختر التثبيت من قائمة المتصفح. |
| Android | افتح الموقع في Chrome واضغط «ثبّت اللعبة» إذا ظهر الزر، أو اختر تثبيت التطبيق من قائمة المتصفح. |
| iPhone وiPad | افتح الموقع في Safari، ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية». |

على iOS، التثبيت يتم من Safari يدويًا. المستودع يحتوي تطبيق الويب التقدمي؛ لا يحتوي حزم متاجر أصلية مثل APK أو IPA.

## بنية المشروع

- `index.html`: الصفحة ودلالات PWA ووسوم التوافق مع iOS.
- `src/chess.js`: قواعد اللعب، تقييم الوضع، والبحث الذي يختار نقلة الخصم.
- `src/main.js`: الرقعة والتفاعل والحفظ المحلي وسجل النقلات.
- `src/style.css`: التنسيق المتجاوب.
- `src/pwa.js` و`sw.js`: التثبيت والتخزين المؤقت للعمل دون اتصال.
- `manifest.webmanifest` و`icons/`: بيانات التطبيق وأيقوناته.
- `scripts/`: خادم تطوير محلي، وتجهيز نسخة النشر، وتوليد الأيقونات.

## البيانات والخصوصية

تُحفظ المباراة ومستوى الصعوبة في `localStorage` على الجهاز الحالي. لا يرسل التطبيق النقلات أو بيانات المستخدم إلى خادم. مسح بيانات الموقع في المتصفح يمسح المباراة المحفوظة.

## تعديل الواجهة أو المحرك

ابدأ بتشغيل `npm run dev`. عدّل قواعد الشطرنج والبحث في `src/chess.js`، وسلوك الواجهة في `src/main.js`، والمظهر في `src/style.css`. عدّل `scripts/generate-icons.mjs` ثم شغّله إذا أردت إعادة إنشاء أيقونات PNG من رسم SVG.
